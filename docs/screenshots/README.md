# Screenshots

Place PNG screenshots here to be referenced by the project README:

- health.png — Screenshot of GET /health returning {"status":"ok"}
- invoke.png — Screenshot of invoking an agent (e.g., alpha-bot or qwen3-8b)
- coverage.png — Screenshot of the HTML coverage summary (generated by `make cov-html`)

Quick tips:
- Start the server: `make run-env` (auto-loads .env) or `make run`.
- Health: open http://localhost:8000/health in your browser or run `curl -s http://localhost:8000/health | jq` and take a screenshot.
- Coverage: run `make cov-html`, then open `htmlcov/index.html` in your browser and screenshot the report.

If you run the app in Docker and need local Ollama, set:
- `OLLAMA_HOST=http://host.docker.internal:11434` (Docker for Mac) so the container can connect to the host Ollama service.
